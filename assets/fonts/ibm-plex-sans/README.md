# IBM Plex Sans

Official WOFF2 files from IBM/plex, commit `71f558992315a12ca1f06a2215d57962a1992162`.
Redistributed under the SIL Open Font License 1.1; see LICENSE.txt.

Regular (400), Medium (500), SemiBold (600), and Italic (400) are loaded
on demand with font-display: swap. The regular face alone is preloaded.
Japanese glyphs use the browser’s sans-serif fallback. No font CDN is needed.
